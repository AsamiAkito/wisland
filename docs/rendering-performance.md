# 动画调度与绘制优化

本分支只修改主窗口帧调度、稳定贴边轮廓和背景采样线程，基于上游 main 独立提交。

- 仅在目标间隔变化时调用 QTimer.setInterval，避免每帧重置活跃定时器；形变开始时恢复既定 16 ms 间隔。
- 稳定贴边且无音乐/按压形变时直接构造贝塞尔外轮廓，减少路径布尔并集；拖动与形变保留原路径。
- 后台尚无截图区域时等待首次请求，停止时仍可唤醒并退出。
- 保留上游动画期间的背景采样策略、16 ms 动画间隔和 33 ms 空闲间隔。

验证：安装项目依赖后，运行 `python -m unittest discover -s tests -v`。离屏检查覆盖四个贴边方向、展开/收起轮廓的像素差、定时器间隔切换与不重复重设、背景线程无请求等待及停止。

这些测试验证绘制与调度行为。实际交互流畅度仍需在相同 DPI、显示器、页面与桌面背景下检查展开、收起、拖动和切页；不将离屏测试结果表述为桌面实际帧率提升。
